ANIME QUIZ WORLD

プライバシーポリシー

制定日：2026年11月1日

本ポリシーは、Anime Quiz World（以下「本サービス」）が利用者に関する情報をどのように扱うかを説明します。

1. 取得する情報

  • アカウント情報：新規登録・ログイン時のメールアドレス、認証状態、認証サービスが発行するユーザー識別子。
  • 登録時の同意記録：利用規約・プライバシーポリシーへの同意日時とバージョン情報を、認証サービスのユーザーメタデータとして送信する場合があります。
  • 端末内の保存情報：選択言語、クイズのプレイ記録、経験値、実績、コレクション等をブラウザのローカルストレージに保存します。ブラウザのデータ消去により失われることがあります。
  • 通信情報：GitHub Pages、Supabase、AniList等の外部サービスは、各サービスの運用に必要な範囲でIPアドレス、ブラウザ情報、アクセスログ等を処理する場合があります。本サービスがそれらすべてを直接取得・管理するわけではありません。

2. 利用目的

取得した情報は、アカウント登録・ログイン、認証状態の維持、不正利用の防止、クイズ機能やプレイ記録の提供、障害対応、サービスの改善に必要な範囲で利用します。

3. 外部サービスへの送信

本サービスは、静的サイトの配信にGitHub Pages、アカウント認証にSupabase、アニメ作品データの取得にAniList API、外部ライブラリの配信にCDN等を利用します。利用時には各サービスへ必要な通信情報が送信されます。各サービスの情報取扱いは、それぞれのプライバシーポリシー・利用条件をご確認ください。

  • Supabase プライバシー情報
  • AniList 利用条件
  • GitHub プライバシー声明

4. 保存と管理

クイズのプレイ記録等は原則として利用者のブラウザ内に保存され、現時点でAQWのオンラインランキングや端末間同期には使用していません。アカウント認証情報はSupabaseの認証機能で処理され、本サービスがパスワードを独自のデータベースに保存することはありません。

5. Cookie・ローカルストレージ等

本サービスは、言語設定やプレイ記録の保存にブラウザのローカルストレージを利用します。認証セッションにはブラウザのセッションストレージを利用する構成です。ブラウザ設定から保存データを削除できますが、削除後は一部機能の設定や記録が失われる場合があります。

6. 情報の第三者提供

法令に基づく場合、利用者の同意がある場合、またはサービス提供に必要な外部事業者への送信を除き、個人情報を販売することを目的としていません。外部サービスにおける処理や法令に基づく開示については、各サービスの方針が適用されます。

7. 安全管理・未成年の利用

不正アクセス等の防止に合理的な措置を講じますが、インターネット上の通信やサービスの安全性を完全に保証することはできません。未成年の方は、必要に応じて保護者と相談したうえで利用してください。公開の問い合わせや投稿には、住所、電話番号、学校名、パスワード等の個人情報を記載しないでください。

8. 本ポリシーの変更

機能や法令等の変更に応じて、本ポリシーを改定する場合があります。変更内容は本ページで告知します。

9. お問い合わせ

情報の取扱いに関する問い合わせは、プロジェクトの問い合わせ窓口をご利用ください。公開の場にメールアドレス等の個人情報を投稿しないでください。

本ポリシーはサービスの現状に基づく説明です。外部サービスの設定や実際のデータ処理に変更があった場合は、内容の更新が必要です。
