# Anime Quiz World

アニメ作品のデータを使った、無料のクイズ・作品検索・おすすめ診断サイトです。

## 公開サイト
- トップページ・クイズ：https://the-rascal-of-sakurasou.github.io/anime-quiz-world/
- おすすめアニメ診断：https://the-rascal-of-sakurasou.github.io/anime-quiz-world/recommend.html

## 主な機能
### アニメクイズ
- 作品画像、作品名、放送年、制作スタジオ、キャラクター、あらすじ等を使った複数の出題形式
- 5段階の難易度選択
- 通常、デイリー、時間制限、連続出題などのプレイモード
- 回答結果、ヒント、間違えた問題の復習
- 実績、経験値、連続プレイ、プレイ履歴
- 日本語を含む複数言語の表示

### 作品検索
- AniListの作品データを利用した作品検索
- 作品画像や基本情報の表示

### おすすめアニメ診断
- 7問の好み診断
- 好きな作品・苦手な作品の任意入力
- 診断回答と作品データに基づくおすすめ候補・新しい作品の提案
- おすすめへの評価を使ったローカルな傾向調整
- 診断結果の共有

### オンライン対戦（開発中）
- [オンライン対戦ルーム](https://the-rascal-of-sakurasou.github.io/anime-quiz-world/multiplayer.html)
- ルーム作成・ルームコード参加・準備状態のリアルタイム表示
- 2〜4人のランダムマッチ（直近の対戦履歴を参照し、同じ相手との連続マッチを抑制）
- 同期クイズ、サーバー側スコア検証、対戦履歴・ランキング、フレンド招待、再戦機能は順次開発

### AQWコミュニティ
- アカウント登録・ログイン
- プロフィール、投稿、返信、いいね、フォロー
- 通知、相互フォローした利用者とのメッセージ
- スピードラッシュのオンラインランキング

## データ・外部サービス
- ホスティング：GitHub Pages
- アニメ作品情報：AniList GraphQL API
- アカウント・コミュニティ・ランキング：Supabase
- クイズの一部の記録、言語設定、おすすめ診断の回答・評価：ブラウザのローカルストレージ

外部サービスの稼働状況、API仕様、通信環境等により、一部機能が利用できない場合があります。ローカルストレージのデータは、ブラウザのデータ消去や端末変更により失われることがあります。

## 開発・公開
本リポジトリはGitHub Pagesで公開しています。公開設定や接続先サービスの設定は、GitHubおよびSupabase側の管理画面で確認してください。
