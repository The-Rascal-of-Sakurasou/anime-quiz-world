# AQW 1対1オンライン対戦 実機テストチェックリスト

このテストは、**異なる2つのAQWアカウント**を使って実施する。アカウントのパスワードや認証コードを相手に共有しない。可能なら別々の端末、難しければ別々のブラウザプロファイルでログインする。

## 1. ルーム作成・参加

- [ ] アカウントAでログインし、オンライン対戦ページを開く
- [ ] 5問を選び、ルームを作成する
- [ ] ルームコードと招待リンクが表示される
- [ ] アカウントBでログインし、コードまたは招待リンクから参加する
- [ ] 参加者が2人を超えない
- [ ] 参加者一覧・ホスト表示・準備状態が両画面で一致する
- [ ] 未準備の状態ではホストが開始できない
- [ ] ホスト以外は開始操作を実行できない
- [ ] 2人とも準備完了後、ホストが開始できる

## 2. 同期クイズ

- [ ] 2人に同じ問題が同じ順序で表示される
- [ ] 選択肢の内容と順序が2人の画面で一致する
- [ ] 制限時間が20秒で、両画面の残り時間が大きくずれない
- [ ] 正解・不正解がサーバー側の判定と一致する
- [ ] 片方が回答済みでも、もう片方は回答できる
- [ ] 同じ人が同じ問題に二重回答できない
- [ ] 期限切れの回答が得点にならない
- [ ] 正解情報が未解決の問題データやRealtime通知に含まれない
- [ ] 5問終了後、両画面に同じ最終スコアと勝敗が表示される

## 3. 再接続・退出・降参

- [ ] 対戦中に片方のページを再読み込みし、同じ対戦状態へ復帰する
- [ ] 再接続後に問題番号・回答状態・スコアが維持される
- [ ] 対戦中に相手が退出した場合、残った側へ終了状態が反映される
- [ ] 降参した側の敗北、相手側の勝利がサーバー側で確定する

## 4. 再戦・戦績・ランキング

- [ ] 終了後、片方から再戦を申請できる
- [ ] 相手が承認した場合だけ新しいルームが作成される
- [ ] 相手が辞退した場合は再戦ルームが作成されない
- [ ] 申請の期限切れが正しく処理される
- [ ] 対戦履歴に相手・日時・結果・スコアが表示される
- [ ] 累計対戦数・勝利数・敗北数・引き分け数が一致する
- [ ] 1対1ランキングに戦績が反映される
- [ ] プロフィールのランキング公開設定がランキング表示に反映される

## 5. ランダムマッチ

- [ ] 2アカウントが同じタイミングで参加すると1対1でマッチする
- [ ] 片方が待機中にキャンセルすると待機状態が解除される
- [ ] キャンセルとマッチ成立が競合しても、二重ルームや多重参加が発生しない
- [ ] 直近で対戦した相手との連続マッチが優先的に避けられる
- [ ] 参加者が少ない場合に同じ相手と再マッチする可能性がある旨が表示どおりである

## 6. 記録する情報

不具合があった場合は、パスワード・メールアドレス・認証コード・アクセストークンを記録せず、次の情報だけを残す。

- テスト日時（日本時間）
- テスト項目番号
- PC / スマートフォン、OS、ブラウザ
- どちらのアカウント側で発生したか（A / B）
- 表示されたエラーメッセージ
- 再現手順
- 個人情報を隠した画面キャプチャ（必要な場合）

**合格条件:** 1〜5の必須項目が両アカウントで正常に完了し、相手の情報・正解情報・管理者情報が権限のないユーザーに漏れないこと。
